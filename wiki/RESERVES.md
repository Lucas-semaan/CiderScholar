# Réserves de la première distillation

La première version inventorie 194 fichiers Word dans le dossier « Fiches validées et importées ». Elle utilise 80 fiches pour construire 11 pages de réflexion. Les 114 autres restent des références situatives à rechercher dans le RAG ou à examiner lors d'une extension du wiki.

## Points à revoir

- Le code `F2c_10` désigne deux fichiers de méthode FMR dont les résumés ne formulent pas de façon identique l'incertitude organoleptique. Le wiki conserve les deux et ne les fusionne pas en conclusion.
- Le code `G3f_10` désigne une fiche générale sur les additifs et un tableau. Les repères utilisent un numéro de variante pour éviter une provenance ambiguë.
- La fiche `H3a_13` porte la mention « à compléter par Savoir Faire » dans son nom malgré son classement dans le dossier validé. Elle ne fonde aucune procédure dans le wiki.
- `Figures_à_demander.docx` et `nettoyage_soutireuse.docx` ne possèdent pas de code de fiche dans leur nom. Elles sont inventoriées comme annexes.
- Plusieurs fiches comportent des données réglementaires ou des valeurs techniques susceptibles d'évoluer. Elles restent dans les sources situatives ; leur actualité doit être vérifiée avant une réponse normative.
- L'extraction native conserve les paragraphes et cellules de tableaux, mais ne transforme pas les figures en connaissances textuelles. Toute conclusion dépendant d'une figure exige la lecture de l'original.

## Limite de provenance

Les repères `pNNNN` sont les rangs des paragraphes dans le XML Word, y compris les cellules de tableaux. Ils assurent une localisation stable pour une empreinte donnée mais ne correspondent pas aux pages imprimées. Les citations destinées à l'utilisateur continuent d'utiliser les pages et métadonnées validées du corpus SQLite.
